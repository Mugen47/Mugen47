### 🧬 SteganoGAN - *AI-Driven Image Steganography*

End-to-end GAN-based steganography system that hides secret binary payloads inside RGB images with near-invisible embedding, error-corrected decoding, and a full-stack application layer.

**Architecture** - U-Net Generator · ResBlock CNN Decoder · DenseNet Discriminator · Spectral Normalization · 3× Repetition ECC with majority voting

| Metric | Value |
|:---|:---|
| PSNR | **34.5 dB** |
| SSIM | **0.96** |
| Final BER (post-ECC) | **0.0%** |
| Inference | **< 2.5s** |
| Training Data | 100K images (STL-10) |

🔒 **Indian Copyright Filing** - Diary No. LD-7768/2026-CO *(under scrutiny)*
